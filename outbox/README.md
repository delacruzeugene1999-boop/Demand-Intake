# outbox/

Triage outputs land here. Do **not** edit files in this folder by hand —
they are regenerated by the GitHub Actions workflow on every push to
`inbox/`.

For each demand file `inbox/<name>.{txt,md}`, two files are produced:

- `outbox/<name>.report.txt` — the formatted 14-section G1 triage report
- `outbox/<name>.json` — the raw structured JSON (same 14 sections,
  machine-readable)

## What the JSON contains

```
demand_intake_status          completeness_assessment
service_family_routing        run_type
subtype                       program_affiliation
materiality                   overlay_triggers
effort_and_cost_bands         provisional_delivery_path
recommended_next_owner_forum  g1_triage_recommendation
triage_note_draft             confidence_and_escalation
```

See `triage/schema.py` for the full schema and `README.md` for the
manual-based decision logic.
