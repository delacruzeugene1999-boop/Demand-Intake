# outbox/

Triage outputs land here. **Do not edit files in this folder by hand** —
they are regenerated by the **Triage Demand** GitHub Actions workflow
on every push to `inbox/`.

For each demand file `inbox/<name>.{txt,md,docx,pdf}`, two outputs are
produced:

| File | Purpose |
|------|---------|
| `outbox/<name>.handoff.md` | The **BTL Hand-Off Pack** — a formatted Markdown brief with the G1 verdict, classification decision, required consultations, open questions, and the audit-trail triage note. Click it on GitHub for a rendered view. |
| `outbox/<name>.json` | The machine-readable record — all 14 triage sections in structured JSON, for downstream automation. |

## Hand-off pack layout

1. **G1 verdict** — one-line call-out
2. **Demand intake & completeness**
3. **Classification decision** (family, run type, subtype, program affiliation, materiality)
4. **Required consultations** (overlays, mandatory first)
5. **Resourcing signal** (effort / cost / confidence)
6. **Provisional delivery path**
7. **Recommended next owner / forum**
8. **Open questions & escalation items**
9. **Triage note** (audit trail)

## JSON fields

```
demand_intake_status          completeness_assessment
service_family_routing        run_type
subtype                       program_affiliation
materiality                   overlay_triggers
effort_and_cost_bands         provisional_delivery_path
recommended_next_owner_forum  g1_triage_recommendation
triage_note_draft             confidence_and_escalation
```

See `triage/schema.py` for the full schema and the top-level `README.md`
for the manual-based decision logic.
